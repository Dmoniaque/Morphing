# Morphing
Projet S3 qui permet de faire un morphing avec 2 images

Nous avons utiliser divers sources pour faire ce projet: stackoverflow, kooR.fr, geeksforgeeks, tutorialspoint, IBM, FFmpeg, reddit, youtube, nos cerveaux, etc. 
Lors d'erreurs que nous n'arrivions pas regler, nous utilisions un peu d'IA.
